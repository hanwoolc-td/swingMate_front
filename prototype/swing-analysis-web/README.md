# SwingMate 웹 스윙 분석 프로토타입

Flutter 기능을 이식하기 전에 영상 위 코치 주석, 자동 자세 관찰의 표시 경계,
편집 기록과 확대 동작을 브라우저에서 검증하기 위한 독립 프로토타입입니다.

## 실행

```sh
cd prototype/swing-analysis-web
npm start
```

브라우저에서 `http://127.0.0.1:8777/index.html`을 엽니다.

## 사용 흐름

1. 로컬 영상을 선택하거나 공개 샘플을 엽니다.
2. 정면/측면 촬영 방향과 카메라 정렬 여부를 확인합니다.
3. 코치 직접 분석에서 직선, 자유선, 3점 각도 또는 수동 궤적을 기록합니다.

주석은 영상 content 영역을 기준으로 0~1 정규화 좌표로 저장됩니다. 실행 취소/다시 실행,
1~4배 확대·이동, 레이어 표시와 브라우저 저장·복원을 지원합니다.

## 자동 분석 데이터

공개 저장소에는 사용자 원본 영상, 사용자 영상에서 추출한 pose JSON과 코치 라벨을 포함하지
않습니다. 따라서 포함된 공개 샘플은 수동 분석 확인용이며 자동 자세 관찰은 비활성화됩니다.

`extract_pose.swift`와 `pose-track.js`는 자동 분석 실험 코드로 남겨두었습니다. 제품에 연결할 때는
파일명 하드코딩 대신 서버의 `videoId`와 접근 권한이 있는 pose artifact를 연결해야 합니다.

자동 경로의 의미는 양손목 중심 관찰값이며 실제 클럽헤드·샤프트 궤적이 아닙니다. 낮은 신뢰도,
손목 누락과 실제 가림 구간은 임의로 연결하지 않습니다. 세부 지표 계약은 `METRICS.md`를
참고하세요.

## 테스트

```sh
npm test
```

좌표 변환, 주석, 워크플로, 편집 기록, 확대, 실패 안내, 손목 경로, 반복성 계산 엔진,
근거 레코드와 지표 계약을 검증합니다.

## 공개 저장소 제외 항목

- 사용자 원본 영상 및 심볼릭 링크
- 사용자 영상에서 추출한 pose JSON
- 사용자별 기준선·재테스트 리포트
- 코치 라벨 및 개인 식별 가능한 분석 결과

`sample.mp4`는 UI 조작 확인을 위한 공개 샘플이며 골프 코칭 정확도 검증 자료가 아닙니다.
