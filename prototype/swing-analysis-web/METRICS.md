# 자동 분석 지표 계약

자동 분석은 하나의 정석 자세와 비교해 좋음/나쁨을 판정하지 않는다. 모든 숫자는 `EvidenceRecord`를 통해서만 표시하고, 근거·입력조건·신뢰도·한계를 함께 보존한다.

## 2D 영상에서 허용하는 관측

| 방향 | 지표 | 계층 | 자동 평가 |
|---|---|---|---|
| 정면 | 척추 측방 기울기, 어깨선, 골반선 | L2 | 관측만 허용 |
| 측면 | 척추 전방 기울기 | L2 | 관측만 허용 |
| 정면/측면 | 양손목 중심 경로 | L3 | 입력 품질 GOOD일 때만 선 표시 |

## 영상만으로 금지하는 값

- 클럽 패스, 페이스 투 패스, 어택 앵글, 다이내믹 로프트
- X-factor와 3D 어깨·골반 회전각
- 지면반력, 압력 중심, 체중 이동
- 허리 부상 위험 또는 의학적 안전 판정

클럽 전달값은 별도의 L4 클럽 검출 또는 론치모니터 입력이 필요하다. 손목 중심 경로를 클럽 궤적으로 부르지 않는다.

## 신뢰도

현재 임계는 검증 전 개발 가정이다. `HIGH >= 0.9`이면서 카메라 정렬 확인, `MEDIUM >= 0.7`, `LOW >= 0.5`, 그 미만은 `UNAVAILABLE`이다. 이는 입력 품질 등급이며 정확도 확률이 아니다.
