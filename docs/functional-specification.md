# SwingMate 기능 명세서

> 골프 프로의 회원·예약·레슨 기록을 한곳에서 관리하는 코칭 CRM

| 항목 | 내용 |
| --- | --- |
| 문서 버전 | v0.6 |
| 작성일 | 2026-08-31 |
| 대상 | iOS·Android 앱 |
| 사용자 | 골프 프로, 레슨 회원 |
| 결제 | 앱 외부에서 처리 |

---

## 1. 제품 정의

SwingMate는 프로가 여러 경로에서 확보한 회원을 통합 관리하고, 회원이 예약부터 레슨 복습까지 이용하는 앱이다.

핵심 기능:

1. 회원·레슨권·예약 통합 관리
2. 회차별 레슨일지·영상·Q&A
3. 레슨 중 `스윙 저장` 버튼으로 직전 영상 클립 저장

초기 버전에서는 프로 검색·매칭, 앱 내 결제, 1:1 채팅과 커뮤니티를 제공하지 않는다.

---

## 2. 사용자와 기본 구조

### 프로

- 여러 회원의 레슨권, 예약, 레슨 기록과 Q&A를 관리한다.
- 레슨권 템플릿, 장소와 예약 가능 일정을 설정한다.

### 회원

- 연결된 프로별 레슨권·예약·레슨 기록을 확인한다.
- 보유 레슨권으로 예약하고 완료된 회차에 Q&A를 남긴다.

### 관계 원칙

- 프로 한 명은 여러 회원을 관리할 수 있다.
- 회원 한 명은 여러 프로와 연결될 수 있다.
- 회원은 앱 상단에서 프로를 변경한다.
- 레슨권·예약·기록·Q&A는 프로별로 분리한다.
- 다른 프로와 회원의 기록에는 접근할 수 없다.

## 3. 핵심 흐름

```text
회원 연결
→ 외부 합의·결제
→ 프로가 레슨권 등록
→ 회원이 예약
→ 레슨 시작·촬영 동의
→ 직전 스윙 클립 저장
→ 레슨 완료
→ 프로가 일지·영상 피드백 작성
→ 회원이 복습·Q&A 작성
→ 필요 시 레슨권 추가 요청
```

## 5. 회원 등록과 연결

### CONNECT-01. 가입 회원

```text
회원이 일회용 코드·QR 표시
→ 프로가 입력·스캔
→ 회원 승인
→ 연결 완료
```

- 코드에는 짧은 유효기간을 둔다.
- 승인 전에는 프로가 회원 기록을 볼 수 없다.

### CONNECT-02. 미가입 회원

```text
프로가 임시 회원 생성
→ 레슨권·기록 관리
→ 초대 링크 전송
→ 회원 가입·본인 확인
→ 기존 기록 연결
```

- 가입 전 기록은 프로만 볼 수 있다.
- 연결할 때 중복 회원 여부를 확인한다.

연결 상태: 대기·연결 중·종료

## 6. 레슨권

### PASS-01. 레슨권 템플릿

프로가 자주 판매하는 레슨 조건을 미리 만든다. 회원이 예약할 때 별도로 선택하는 항목은 아니다.

입력 항목:

- 템플릿명
- 설명
- 회당 레슨 시간
- 예약 시작 간격
- 활성화 여부

예시:

| 템플릿명 | 레슨 시간 | 예약 시작 간격 |
| --- | ---: | ---: |
| 1:1 개인 레슨 | 50분 | 60분 |
| 원포인트 레슨 | 15분 | 30분 |

- 이미 발급한 레슨권은 템플릿을 수정해도 바뀌지 않는다.
- 사용 이력이 있는 템플릿은 삭제하지 않고 비활성화한다.

### PASS-02. 레슨권 등록

외부에서 조건·결제를 합의한 뒤 프로가 등록한다.

입력 항목:

- 회원
- 레슨권 템플릿
- 총 횟수
- 시작일 — 등록일로 자동 기록, 필요 시 수정
- 유효기간 — 선택

예시:

```text
김민수 회원
1:1 개인 레슨 · 50분 · 10회
잔여 10회
```

- 레슨권에는 발급 당시 템플릿명과 시간을 복사해 보관한다.
- 등록 즉시 회원에게 알림을 보낸다.
- 재등록할 때 기존 횟수를 늘리지 않고 새 레슨권을 만든다.
- 레슨권은 사용 중·소진·만료·취소 상태로 관리한다.

### PASS-03. 차감·복원

- 예약 확정 시 잔여 횟수를 1회 차감한다.
- 예약 시간만 변경하면 추가 차감하지 않는다.
- 취소 기한 전 회원 취소 또는 프로 취소 시 1회 복원한다.
- 기한 이후 취소와 노쇼는 프로가 복원 여부를 결정한다.
- 레슨 완료 시 추가 차감하지 않는다.
- 예약 실패·중복 요청에는 차감하지 않는다.

### PASS-04. 레슨권 추가 요청

```text
회원이 추가 요청
→ 프로가 외부에서 상담·결제
→ 프로가 새 레슨권 등록
→ 요청 자동 완료
```

- 요청은 구매나 결제 완료를 의미하지 않는다.
- 상태는 요청·완료·거절·회원 취소로 관리한다.

## 7. 예약

### BOOKING-01. 장소 등록

- 장소명
- 주소·상세 위치
- 안내
- 활성화 여부

비활성화한 장소는 새 예약에 표시하지 않되 기존 예약에는 유지한다.

### BOOKING-02. 가능 일정 설정

프로 설정 항목:

- 요일별 운영시간
- 특정일 휴무·운영시간 변경·추가 오픈
- 특정 시간 차단
- 예약 오픈 범위 — 기본 30일
- 예약·취소 마감 — 기본 레슨일 전날 23:59

규칙:

- 다른 예약·휴무·차단 일정과 겹치는 시간은 표시하지 않는다.
- 장소가 달라도 같은 프로의 시간이 겹치면 예약할 수 없다.
- 외부 플랫폼 예약과 장소 이동 시간은 프로가 직접 차단한다.
- 외부 캘린더 자동 연동은 MVP에서 제외한다.

### BOOKING-03. 회원 셀프 예약

조건:

- 해당 프로와 연결 중이다.
- 사용 중이며 잔여 횟수가 있는 레슨권이 있다.

선택 순서:

```text
사용할 레슨권 확인
→ 날짜
→ 장소
→ 시간
→ 예약하기
```

- 사용 가능한 레슨권이 하나면 자동 선택한다.
- 여러 개면 먼저 사용할 레슨권을 선택한다.
- `레슨 유형`은 따로 선택하지 않는다.
- 시간 목록은 선택한 레슨권의 레슨 시간과 예약 시작 간격으로 계산한다.
- 모든 활성 장소를 선택할 수 있다.

예시:

```text
1:1 개인 레슨 · 50분
강남 골프 스튜디오
2026년 9월 3일 14:00

레슨권 1회 차감 예정
예약 후 잔여 5회

[예약하기]
```

확정 규칙:

- `예약하기`를 누를 때 슬롯·연결 상태·잔여 횟수를 다시 확인한다.
- 예약 생성·시간 확정·1회 차감을 한 번에 처리한다.
- 동시에 같은 시간을 요청하면 먼저 처리된 한 건만 확정한다.
- 실패하면 차감하지 않고 최신 시간 목록을 다시 보여준다.
- 성공하면 양측에 알림을 보낸다.

### BOOKING-04. 프로의 직접 예약

- 회원과 사용할 레슨권을 선택한 뒤 날짜·장소·시간을 등록한다.
- 회원 예약과 동일하게 확정 시 1회 차감한다.
- 마감 시간 이후에도 빈 시간에는 프로가 직접 등록할 수 있다.

### BOOKING-05. 변경·취소·완료

- 회원은 예약 변경을 프로에게 요청한다.
- 프로는 빈 시간을 확인한 후 변경한다.
- 취소 기한 전에는 회원이 직접 취소할 수 있다.
- 기한 이후에는 프로에게 요청한다.
- 프로가 완료·노쇼 상태를 처리한다.

예약 상태: 확정·취소·완료·노쇼

## 8. 레슨 진행과 영상 촬영

### LESSON-01. 레슨 시작

- 프로가 오늘의 예약에서 `레슨 시작`을 누른다.
- 레슨일지 초안을 자동 생성한다.
- 촬영 전에 회원 동의를 확인하고 일시를 기록한다.
- 회원은 항상 허용하거나 동의를 철회할 수 있다.
- 동의하지 않으면 영상 없이 일지만 작성한다.

### VIDEO-01. 순환 촬영

- 전체 레슨 파일을 만들지 않고 최근 약 15초만 기기에 순환 보관한다.
- 오래된 영상 조각은 자동으로 교체한다.
- 전체 레슨 영상은 서버에 저장하지 않는다.
- 종료·복구 후 임시 데이터를 삭제한다.
- 발열·저장 공간 부족·촬영 중단을 프로에게 알린다.

### VIDEO-02. 직전 스윙 저장

- `스윙 저장` 버튼을 누르면 전 15초와 후 3초를 후보 클립으로 저장한다.
- 저장 성공 시 번호와 썸네일을 표시한다.
- 레슨 종료 후 프로가 선택한 클립만 서버에 업로드한다.
- 미선택 클립은 삭제하고 업로드 실패 클립은 재시도할 수 있다.

MVP는 화면 버튼만 지원한다. 리모컨·스마트워치·음성 명령은 제외한다.

### VIDEO-03. 출시 전 기술 검증

- 50분 이상 촬영 안정성
- 발열·배터리·저장 공간
- 전화·알림·앱 전환 후 복구
- 저장 구간의 정확성
- 업로드 재시도와 임시 데이터 삭제

검증이 부족하면 일반 숏폼 직접 촬영·업로드를 우선 제공한다.

## 9. 레슨일지와 영상 피드백

### LOG-01. 레슨일지

프로 입력 항목:

- 회차 제목·오늘의 목표
- 주요 교정 내용·잘된 점
- 다음 연습 과제
- 회원 공개 메모
- 프로 전용 메모

- 작성 중 자동 저장한다.
- 초안과 프로 전용 메모는 회원에게 보이지 않는다.
- 프로가 작성 완료하면 회원에게 표시하고 알림을 보낸다.

### LOG-02. 회차 열람

| 레슨 상태 | 회원에게 표시 |
| --- | --- |
| 예정 | 날짜·시간·장소·레슨권 정보 |
| 진행 중 | 일지·영상 숨김 |
| 완료 | 일지·영상·Q&A 화면 열람 가능 |
| 취소 | 레슨 기록에서 제외 |

- 일지와 영상은 준비된 항목부터 각각 표시한다.
- 콘텐츠가 없으면 `아직 작성된 레슨일지가 없습니다`, `저장된 스윙 영상이 없습니다`를 표시한다.

### VIDEO-04. 선 그리기

- 정지 프레임에 직선·원·화살표·각도를 표시한다.
- 색상·굵기와 선 표시 켜기·끄기를 제공한다.
- 주석은 원본과 별도 저장하며 영상 전체 구간의 같은 위치에 표시한다.
- 노출 시간 설정·객체 추적·움직이는 선은 제외한다.

## 10. 회원 앱과 Q&A

### MEMBER-01. 회원 홈

- 선택한 프로와 프로 변경 메뉴
- 레슨권 총 횟수·잔여 횟수
- 다음 예약·새 레슨 예약
- 최근 완료 회차
- 답변 도착 Q&A
- 레슨권 추가 요청

### MEMBER-02. 레슨 기록

- 선택한 프로의 회차만 회차순으로 표시한다.
- 예정 회차는 일정 정보만, 완료 회차는 일지·영상·Q&A를 표시한다.

### QNA-01. 회차별 Q&A

- 회원은 완료 회차에서 질문한다.
- 일지가 없어도 완료 회차에는 질문할 수 있다.
- 프로 답변과 회원의 추가 질문을 지원한다.
- 질문은 해당 프로·회차에 연결한다.
- 실시간 채팅, 입력 상태와 읽음 표시는 제공하지 않는다.

질문 상태: 답변 대기·답변 완료·추가 질문·해결

## 11. 알림

프로:

- 회원 연결, 새 예약, 새 질문
- 레슨권 추가 요청
- 레슨일지 작성 대기

회원:

- 프로 연결, 레슨권 등록·변경
- 예약 확정·변경·취소·리마인드
- 레슨일지·영상 등록, Q&A 답변
- 레슨권 추가 요청 처리

MVP는 앱 푸시와 앱 내 알림함을 제공한다.

## 12. 개인정보와 안정성

- 영상 촬영 동의와 철회 이력을 기록한다.
- 영상·일지는 해당 프로와 회원만 접근할 수 있다.
- 영상 원본 주소는 공개하지 않는다.
- 영상 삭제 요청과 연결 종료 후 보관 정책을 제공한다.
- 예약 확정·차감, 취소·복원은 각각 한 번에 처리한다.
- 중복 탭·네트워크 재시도로 중복 예약·차감·복원이 발생하지 않아야 한다.
- 임시 영상 삭제에 실패하면 다음 실행에서 다시 삭제한다.
- 레슨권·예약·일지·영상의 주요 변경 이력을 보관한다.
- 촬영 동의와 보관 정책은 출시 전 개인정보·법률 검토를 거친다.

## 15. MVP 완료 조건

- [ ] 가입·미가입 회원을 모두 등록하고 여러 프로를 전환할 수 있다.
- [ ] 프로가 템플릿으로 레슨권을 발급하고 횟수를 관리할 수 있다.
- [ ] 회원은 레슨 유형을 다시 고르지 않고 보유 레슨권으로 예약할 수 있다.
- [ ] 예약·취소 시 횟수 차감과 복원이 정확하고 중복 처리되지 않는다.
- [ ] 실제 가능한 시간만 표시하고 중복 예약을 차단한다.
- [ ] 촬영 동의 후 순환 촬영과 직전 스윙 저장이 안정적으로 동작한다.
- [ ] 전체 레슨 영상은 서버에 저장되지 않는다.
- [ ] 프로가 일지·영상 주석을 제공하고 회원이 완료 회차에서 확인할 수 있다.
- [ ] 회원이 완료 회차에 Q&A를 남길 수 있다.
- [ ] 다른 프로·회원의 기록에 접근할 수 없다.
